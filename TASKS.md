## Post-review fixes applied (integrator)
- `Message::Quit` + `TrayAction::Quit` now call `iced::window::close` (via
  `get_oldest().then`) so the app actually exits instead of running dead workers.
- `QuickPaste(n)` now restores the nth visible history entry (was a no-op).
- `clear_on_exit` now sends `DbCommand::ClearAll` (FIFO before Shutdown) on quit.
- Removed the duplicate startup Search (supervisor already queues one).
- `AppState::new()` failure no longer panics — falls back to an inert state with
  a visible error (no unwrap/expect in runtime paths).

## Remaining (honest gaps)
- Manual smoke tests (steps in PACKAGING.md §5) require a live Windows desktop
  session + real clipboard; not automatable headlessly here.
- `ShowWindow`/`HideWindow` messages and `signal_existing()` broadcast are wired
  but a running instance does not yet register a listener for the show message
  (message-only windows don't receive HWND_BROADCAST) — documented limitation.
- `ignored_apps` is stored but not enforced in the listener (pause IS enforced
  via `AtomicBool`).
- 3 superseded scaffold files (`clipboard_listener.rs`, `hotkeys.rs`, `tray.rs`)
  remain on disk but are NOT declared as modules and are NOT compiled.
